# Roadmap

| Marco | Escopo | Resultado |
| --- | --- | --- |
| M1 | engine, lead, RBAC, auditoria e API | fundação isolada e segura |
| M2 | distribuição e n8n | automação orientada a eventos |
| M3 | dashboard Vue e relatórios exportáveis | gestão comercial diária |
| M4 | SLA, metas, funil configurável e previsão | governança e performance |
| M5 | data warehouse, BI e catálogo de integrações | escala analítica e ecossistema |

Priorize M1 e M2 em uma conta piloto. M3 só deve usar métricas validadas com a operação; M4/M5 devem ser definidos depois que houver volume histórico suficiente.
